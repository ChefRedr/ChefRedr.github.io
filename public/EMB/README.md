# EMB Revenue Cycle Management Dashboard

A comprehensive client dashboard for EMB's Revenue Cycle Management system, built with vanilla HTML, CSS, and JavaScript.

## Features

### 🏥 Client Manager Perspective
The dashboard is designed from the perspective of a client manager who oversees multiple healthcare practices and their revenue cycle operations.

### 📊 Four Main Tabs

#### 1. Overview Tab
- **Interactive Charts**: Monthly revenue trends, claims status distribution, and client performance
- **Key Metrics Cards**: Total revenue, claims count, average processing time, and collection rates
- **Drag-and-Drop Widgets**: Customizable dashboard layout with sortable widgets
- **Real-time Data Visualization**: Using Chart.js for professional charts

#### 2. Data Tab
- **Comprehensive Tables**: Detailed insurance claims and patient information
- **Advanced Filtering**: Filter by client and date ranges
- **Financial Summary**: Total billed, collected, outstanding, and write-off amounts
- **Status Tracking**: Visual status badges for claims (Paid, Pending, Denied, Under Review)

#### 3. Messaging Tab
- **Live Chat Interface**: Real-time messaging system with EMB support
- **Message History**: Persistent chat history with timestamps
- **Status Indicators**: Online/offline status with animated indicators
- **Responsive Design**: Mobile-friendly chat interface

#### 4. Client Management Tab
- **Client Cards**: Visual representation of each healthcare practice
- **Add/Remove Clients**: Full CRUD operations for client management
- **Client Statistics**: Monthly revenue, patient count, and collection rates
- **Contact Information**: Complete client details and contact info

### 🎨 Design Features

#### Black and Blue Gradient Theme
- **Primary Background**: Deep black to navy blue gradient (135deg)
- **Accent Colors**: Blue gradients (#64b5f6, #42a5f5, #2196f3)
- **Glass Morphism**: Translucent cards with backdrop blur effects
- **Responsive Design**: Mobile-first approach with breakpoints

#### Interactive Elements
- **Hover Effects**: Smooth transitions and elevation changes
- **Custom Scrollbars**: Styled scrollbars matching the theme
- **Loading Animations**: Smooth loading states and transitions
- **Notification System**: Toast notifications for user actions

### 📈 Sample Data Structure

The dashboard includes realistic sample data for:
- **5 Healthcare Practices**: Different specialties (Family Practice, Cardiology, Pediatrics, Orthopedics, Internal Medicine)
- **10 Insurance Claims**: Various procedures, amounts, and statuses
- **10 Patient Records**: Complete patient information with insurance details
- **Monthly Revenue Data**: 12 months of historical revenue data
- **Performance Metrics**: Collection rates and processing times

### 🔧 Technical Implementation

#### Technologies Used
- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Advanced styling with gradients, animations, and responsive design
- **Vanilla JavaScript**: ES6+ features with class-based architecture
- **Chart.js**: Professional data visualization library
- **SortableJS**: Drag-and-drop functionality for widget customization

#### Key Features
- **Modular Architecture**: Clean separation of concerns
- **Event-Driven**: Comprehensive event handling system
- **Local Storage**: Persistent dashboard layout preferences
- **Error Handling**: Graceful error management
- **Performance Optimized**: Efficient DOM manipulation and chart rendering

### 🚀 Getting Started

1. **Clone or Download** the project files
2. **Open `index.html`** in a modern web browser
3. **No build process required** - runs directly in the browser
4. **All dependencies** are loaded via CDN
